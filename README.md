# ชุดภาษาไทยสำหรับ VS Code

ชุดภาษาไทยช่วยให้ใช้งาน UI ของ VS Code เป็นภาษาไทยได้

## การใช้งาน

สามารถเปลี่ยนภาษา UI เริ่มต้นได้โดยกำหนดภาษาที่แสดงของ VS Code ด้วยคำสั่ง **กำหนดค่าภาษาที่แสดง**

กด `Ctrl+Shift+P` เพื่อเปิด **Command Palette** แล้วเริ่มพิมพ์ `display` เพื่อกรองและแสดงคำสั่ง **กำหนดค่าภาษาที่แสดง**

กด `Enter` เพื่อแสดงรายการภาษาที่ติดตั้งไว้ พร้อมไฮไลต์ภาษาปัจจุบัน เลือกภาษาอื่นเพื่อเปลี่ยนภาษา UI

ดูข้อมูลเพิ่มเติมได้ที่ [เอกสาร](https://go.microsoft.com/fwlink/?LinkId=761051)

## การมีส่วนร่วม

สตริงคำแปลดูแลโดย [Unipivot](https://unipivot.com) ซึ่งเป็นแพลตฟอร์มการแปลเป็นภาษาท้องถิ่นที่ขับเคลื่อนด้วยเอเจนต์ ที่เก็บโค้ด vscode-language-pack-th ไม่รับ pull request ที่มีการเปลี่ยนแปลงคำแปล

#  Thai Language Pack for VS Code

The Thai Language Pack provides a localized UI experience for VS Code.

## Usage

You can override the default UI language by explicitly setting the VS Code display language using the **Configure Display Language** command.

Press `Ctrl+Shift+P` to bring up the **Command Palette** then start typing `display` to filter and display the **Configure Display Language** command.

Press `Enter` to display a list of installed languages, with the current language highlighted. Select another language to switch UI language.

See [Docs](https://go.microsoft.com/fwlink/?LinkId=761051) for more information.
